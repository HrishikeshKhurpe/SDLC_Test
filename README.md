# Calculator API

A simple FastAPI application that performs basic arithmetic operations.

## Features

-   Performs addition, subtraction, multiplication, and division.
-   Accepts JSON requests.
-   Returns JSON responses.
-   Includes basic error handling for invalid operations and division by zero.
-   Containerized with Docker.

## Getting Started

### Prerequisites

-   Python 3.8+
-   Docker (optional, for running in a container)

### Installation & Running Locally

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/calculator-api.git
    cd calculator-api
    ```

2.  **Create and activate a virtual environment:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

3.  **Install dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the application:**

    ```bash
    uvicorn src.main:app --reload
    ```

The API will be available at `http://127.0.0.1:8000`.

### Running with Docker

1.  **Build the Docker image:**

    ```bash
    docker build -t calculator-api .
    ```

2.  **Run the Docker container:**

    ```bash
    docker run -p 8000:8000 calculator-api
    ```

The API will be available at `http://127.0.0.1:8000`.

## API Documentation

The API documentation is automatically generated by FastAPI and is available at:

-   **Swagger UI:** `http://127.0.0.1:8000/docs`
-   **ReDoc:** `http://127.0.0.1:8000/redoc`

### Endpoint: `/calculate`

-   **Method:** `POST`
-   **Description:** Performs a calculation based on the provided operands and operation.
-   **Request Body:**

    ```json
    {
        "operand1": 10,
        "operand2": 5,
        "operation": "divide"
    }
    ```

    -   `operand1` (number, required): The first number.
    -   `operand2` (number, required): The second number.
    -   `operation` (string, required): The operation to perform. Supported values are `add`, `subtract`, `multiply`, `divide`.

-   **Success Response (200 OK):**

    ```json
    {
        "result": 2
    }
    ```

### Error Response

#### 400 Bad Request

If the operation is invalid or a calculation error occurs (like division by zero), the API will return a `400 Bad Request` status code with a JSON body describing the error.

**Example (Invalid Operation):**

```json
{
    "detail": "Invalid operation 'modulo'. Supported operations are: add, divide, multiply, subtract"
}
```

**Example (Division by Zero):**

```json
{
    "detail": "Division by zero is not allowed."
}
```

#### 422 Unprocessable Entity

If the request body is malformed or does not match the expected schema (e.g., providing a string where a number is expected), the API will return a `422 Unprocessable Entity` status code. This is handled automatically by FastAPI's data validation.

**Example (Invalid Data Type):**

Request body:
```json
{
    "operand1": "five",
    "operand2": 3,
    "operation": "add"
}
```

Response body:
```json
{
    "detail": [
        {
            "loc": [
                "body",
                "operand1"
            ],
            "msg": "value is not a valid integer",
            "type": "type_error.integer"
        }
    ]
}
```
